# Спрайты и иконки для системы боя

## Требования к спрайтам

### Размеры и форматы
- **Иконки оружия**: 32x32 пикселя, PNG формат
- **Спрайты снарядов**: 16x16 пикселя, PNG формат  
- **Иконки овермапа**: 32x32 пикселя, PNG формат
- **Эффекты**: 64x64 пикселя, PNG формат с прозрачностью

## Структура файлов

### 1. Иконки оружия (`icons/obj/weapons.dmi`)
```
ship_weapon_base.dmi      # Базовая иконка оружия
kinetic_cannon.dmi        # Кинетическая пушка
laser_cannon.dmi          # Лазерная пушка
missile_launcher.dmi      # Ракетная установка
energy_cannon.dmi         # Энергетическая пушка

# Статусные оверлеи
[icon]_status.dmi         # Индикатор состояния (цветной)
[icon]_charge.dmi         # Индикатор заряда
```

### 2. Спрайты снарядов (`icons/obj/projectiles.dmi`)
```
ship_kinetic.dmi          # Кинетический снаряд
ship_laser.dmi            # Лазерный луч
ship_missile.dmi          # Ракета
ship_energy.dmi           # Энергетический заряд
```

### 3. Иконки овермапа (`icons/obj/overmap.dmi`)
```
projectile.dmi            # Базовый снаряд на овермапе
projectile_laser.dmi      # Лазерный снаряд
projectile_kinetic.dmi    # Кинетический снаряд
projectile_missile.dmi    # Ракета
projectile_energy.dmi     # Энергетический снаряд

ship_destroyed.dmi        # Уничтоженный корабль
hit_1.dmi                 # Эффект попадания 1
hit_2.dmi                 # Эффект попадания 2
hit_3.dmi                 # Эффект попадания 3
```

### 4. Эффекты (`icons/effects/effects.dmi`)
```
muzzle_flash.dmi          # Вспышка выстрела
explosion.dmi             # Взрыв
sparks.dmi                # Искры
ship_trail.dmi            # След корабля
```

## Цветовая схема

### Оружие
- **Кинетическое**: Серый (#808080)
- **Лазерное**: Голубой (#00FFFF)
- **Ракетное**: Красный (#FF0000)
- **Энергетическое**: Фиолетовый (#800080)

### Статусы
- **Готово**: Зеленый (#00FF00)
- **Зарядка**: Желтый (#FFFF00)
- **Огонь**: Красный (#FF0000)
- **Повреждено**: Темно-красный (#800000)
- **Отключено**: Серый (#808080)

### Эффекты
- **Вспышка**: Белый (#FFFFFF) с оранжевым оттенком
- **Взрыв**: Оранжево-красный градиент
- **Искры**: Желто-оранжевый (#FFA500)

## Анимации

### Выстрел
1. **Вспышка**: Быстрая (5 кадров)
2. **Дым**: Медленная (10 кадров)
3. **Отдача**: Легкое смещение оружия

### Попадание
1. **Вспышка**: Мгновенная (1 кадр)
2. **Взрыв**: Средняя (8 кадров)
3. **Дым**: Длительная (15 кадров)

### Полёт снаряда
1. **Движение**: Плавное перемещение
2. **Свечение**: Пульсирующая альфа-канал
3. **След**: Полупрозрачный след

## Создание спрайтов

### Инструменты
- **Aseprite** (рекомендуется)
- **GraphicsGale**
- **GIMP** с плагинами для пиксель-арта
- **Paint.NET**

### Техники
1. **Пиксель-арт**: Четкие границы, ограниченная палитра
2. **Антиалиасинг**: Минимальный, только для плавных градиентов
3. **Ограничение цветов**: 16-32 цвета на спрайт
4. **Консистентность**: Единый стиль для всех спрайтов

## Примеры кода для спрайтов

### Базовый спрайт оружия
```dm
/obj/machinery/ship_weapon/kinetic
    icon = 'icons/obj/weapons.dmi'
    icon_state = "kinetic_cannon"
    
    // Статусный оверлей
    var/status_overlay
    
    update_icon()
        . = ..()
        cut_overlay(status_overlay)
        
        var/mutable_appearance/status = mutable_appearance(icon, "[icon_state]_status")
        switch(weapon_state)
            if(WEAPON_STATE_READY)
                status.color = COLOR_GREEN
            if(WEAPON_STATE_CHARGING)
                status.color = COLOR_YELLOW
            // ... и т.д.
        
        status_overlay = status
        add_overlay(status)
```

### Спрайт снаряда на овермапе
```dm
/obj/overmap/projectile
    icon = 'icons/obj/overmap.dmi'
    icon_state = "projectile"
    
    update_icon()
        . = ..()
        
        if(projectile)
            switch(projectile.weapon?.weapon_type)
                if(WEAPON_TYPE_LASER)
                    icon_state = "projectile_laser"
                    color = COLOR_CYAN
                if(WEAPON_TYPE_KINETIC)
                    icon_state = "projectile_kinetic"
                    color = COLOR_GRAY
                // ... и т.д.
        
        // Прозрачность по прогрессу
        alpha = 150 + (current_progress * 105)
```

## Оптимизация

### Размер файлов
- **Сжатие PNG**: Использовать pngquant или optipng
- **Удаление метаданных**: Stripping EXIF данных
- **Объединение спрайтов**: Использовать спрайтшиты

### Производительность
- **Минимизация оверлеев**: Использовать только необходимые
- **Кэширование спрайтов**: Предзагрузка часто используемых
- **Оптимизация анимаций**: Использовать минимальное количество кадров

## Генерация placeholder спрайтов

Если нет художника, можно использовать простые геометрические формы:

### Оружие
- **Кинетическое**: Серый прямоугольник с дулом
- **Лазерное**: Голубой цилиндр с линзой
- **Ракетное**: Красная труба с конусом
- **Энергетическое**: Фиолетовая сфера с катушками

### Снаряды
- **Кинетический**: Серый круг
- **Лазерный**: Голубой луч
- **Ракета**: Красная стрела
- **Энергетический**: Фиолетовый шар

### Эффекты
- **Вспышка**: Белый круг
- **Взрыв**: Оранжевые кольца
- **Искры**: Желтые точки

## Интеграция с существующими спрайтами

Система использует существующие спрайты из:
- `icons/effects/effects.dmi` для базовых эффектов
- `icons/obj/projectiles.dmi` для снарядов
- `icons/obj/overmap.dmi` для овермапа

Новые спрайты добавляются в соответствующие DMI файлы или создаются новые.

## Лицензирование спрайтов

Все созданные спрайты должны быть:
1. Совместимы с лицензией проекта Solaris
2. Оригинальными или иметь соответствующую лицензию
3. Отмечены авторством при использовании чужих работ

## Контакты для художников

Если нужны профессиональные спрайты:
1. Обратиться к художникам сообщества Solaris
2. Использовать ресурсы из открытых источников
3. Нанять художника-фрилансера

## Обновление спрайтов

При обновлении спрайтов:
1. Сохранять обратную совместимость
2. Обновлять все связанные спрайты
3. Тестировать на разных разрешениях
4. Обновлять документацию
